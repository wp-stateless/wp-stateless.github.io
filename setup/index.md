## Welcome to the WP-Stateless Setup Manual!

This guide will walk you through the process of setting up **Google Cloud Platform (GCP)** for use with the WP-Stateless WordPress plugin. By following the steps below, you’ll be able to offload and serve your media directly from Google Cloud Storage.

The setup process includes the following steps:

1. Create a Google Cloud [Billing Account](/setup/billing-account/)
2. Create a Google Cloud [Project](/setup/project/)
3. Create a Google Cloud [Bucket](/setup/bucket/)
4. Create a Google Cloud [Service Account](/setup/service-account/)
5. Configure [WP-Stateless Settings](/setup/wp-stateless/)

**A Note for Experienced Users:**
If you are already familiar with Google Cloud Platform, please pay special attention to **Step 3.2** in the [bucket setup guide](/setup/bucket/). These specific settings are crucial to prevent issues and ensure the WP-Stateless plugin works correctly with your bucket.
