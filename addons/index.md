Some WordPress plugins override or provide additional features for the Media Library, image upload, and processing. These add-ons offer compatibility features to ensure smooth operation and support the behavior of other plugins alongside WP-Stateless.

If you experience any issues please contact us on <a href="https://github.com/udx/wp-stateless/issues" target="_blank" rel="noreferrer nofollow">GitHub</a> or <a href="https://wordpress.org/support/plugin/wp-stateless/" target="_blank" rel="noreferrer nofollow">Support page</a>.
